# Shots

Screenshots from the real recording go here. The chapters will use them once they exist.

## How to capture

- Keep raw recordings (OBS, Game Bar) on a non-system drive, never C:, and never in this repo.
- Screenshots: Win + Shift + S on Windows, Shift + Cmd + 4 on Mac.
- Save as **PNG**, about 1600 px wide, using the exact file names below. Crop to the Jan window.
- Use harmless chats only. No real names, emails or file paths you would not publish. Blur your user name in paths if you want.
- Drop the files in this folder and say so. They will be renamed if needed, compressed, and wired into the chapters and the site.
